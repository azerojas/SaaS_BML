# Contrato REST

Fuente consolidada: [reporting-api.md](../../../docs/reporting-api.md), [OpenAPI 1.5.0](../../../docs/openapi.json), [ejemplos](../examples/api-examples.json).

Diez endpoints GET privados bajo `/api/v1/analytics/` y `/api/v1/reports/export.xlsx`. Rango semiabierto, Lima, Decimal JSON como cadena, cuatro permisos independientes y advertencias financieras obligatorias. Ver contrato principal para filtros compatibles, top/paginación, metadatos, fórmula de cada indicador y cabeceras Excel.
